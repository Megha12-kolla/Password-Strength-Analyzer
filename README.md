# 🔐 Password Strength Analyzer

A simple Python application that analyzes the strength of a password based on common security rules. It checks for uppercase letters, lowercase letters, digits, special characters, and minimum password length to provide instant feedback.

---

## ✨ Features

- 🔠 Detects uppercase letters
- 🔡 Detects lowercase letters
- 🔢 Detects digits
- 🔐 Detects special characters
- 📏 Checks if the password has at least 8 characters
- ✅ Displays a password analysis report
- 💪 Indicates whether the password is strong or needs improvement
